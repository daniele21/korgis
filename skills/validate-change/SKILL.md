# Validate Change
Use the native selector to resolve outcome/owner -> risks -> gates -> profile. Contained work stays focused; shared runtime/API/security/persistence/lifecycle/package changes strengthen; selector/global/toolchain/unknown/release is FULL.

Classify failures before patching. Each failed repair needs a falsifiable hypothesis; **after two failed repairs with the same signature, change diagnostic strategy and gather new evidence before a third**. Never weaken a legitimate gate. Deterministic hosted evidence never proves Apple Silicon behavior.

At integration run affected automated critical E2E, with `FULL_MEDIA` for material UI/UX outcomes; physical Apple Silicon evidence is `DEFERRED_TO_RELEASE`. Report bounded source identity, risks/profile, gate reasons/status, evidence refs, gaps and next action without hiding FAIL/PENDING.
